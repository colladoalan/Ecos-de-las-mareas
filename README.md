# El Eco de las Mareas

Documentación de producción del proyecto "El Eco de las Mareas" (The Echo of the Tides) — equipo MESA CHICA, para el Future Vision XPRIZE.

## Ver el centro de documentos

Abrí `index.html` (o "El Eco de las Mareas.html") en el navegador — ahí está todo: fichas de personajes, la embarcación, escenografías, y los prompts de producción del tráiler.

Si activás GitHub Pages en este repo (Settings → Pages → branch `main`), va a quedar publicado automáticamente en una URL pública.

## Estructura

- `El Eco de las Mareas.html` / `index.html` — centro de documentos interactivo (mismo archivo, dos nombres)
- `assets/` — fotos de referencia de personajes y diagramas
- `ficha_*.md` — fichas de personajes (Clara, Tomás, Mateo, Sofía, Alfi, Vicente) y del Benteveo
- `escenografias.md` — locaciones principales del tráiler
- `prompts_imagenes_el_eco_de_las_mareas.md`, `prompts_dobles_por_plano.md`, `planos_video_por_escena.md` — prompts de generación de imagen/video
- `storyboard_el_eco_de_las_mareas.html` — storyboard del tráiler
